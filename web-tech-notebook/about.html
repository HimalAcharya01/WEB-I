About Us

This site is a small project for the Web Tech lab. The idea was to make a few connected pages with a navigation bar, use CSS for the layout, and keep the code in separate files instead of writing everything in one place. That is why the styling is in one CSS file and the scripts are in one JavaScript file, and every page uses the same two.

While building it I found out that keeping things separate really does save time. When I wanted to change the colour of the menu I only had to edit one line, and all three pages changed together. Before this I would have copied the style into every page.

What I used

  • HTML for the structure of each page
  • CSS with Flexbox and Grid for the layout
  • JavaScript for the menu button and the contact form
  • GitHub Pages to put it online
